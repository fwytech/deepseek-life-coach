# Trae Five

本项目是一个基于 HTML5、CSS 和 Node.js 的网页应用，旨在通过火山方舟 DeepSeek R1 API 实现与 AI 的对话，帮助用户成长为更好的自己，成为你的 life coach。

## 版本历史

### v1.1.0 - 当前版本
- 系统功能优化
  - 跨域请求处理
  - 错误处理和异常捕获
  - 请求超时控制（60秒）
  - 静态文件服务

### v1.0.0 - 基础版本
- 基础对话功能实现
  - 支持用户与 AI 进行文本对话
  - 集成火山方舟 DeepSeek R1 API
  - 实现流式响应，提供实时反馈

## 项目特性
- 前后端分离架构
- 流式响应技术，实现打字机效果
- 完善的错误处理机制
- 支持大规模文本输入（限制2MB）

## 技术栈
- 前端：HTML5、CSS、JavaScript
- 后端：Node.js、Express
- API：火山方舟 DeepSeek R1

## 交互流程
1. 用户在前端输入问题，点击发送
2. 前端将问题通过 AJAX 请求发送到 Node.js 后端
3. 后端调用 DeepSeek R1 API，返回 AI 回复
4. 前端展示 AI 回复内容

## 后续优化方向
- 对话上下文记忆功能
- 多轮对话和消息滚动
- SVG 图标界面美化
- 图片和媒体资源优化
- 主流浏览器兼容性支持

## 快速开始
1. 安装依赖：
```bash
npm install
```

2. 启动服务：
```bash
npm start
```

3. 访问应用：
打开浏览器访问 http://localhost:3000

## 注意事项
- 确保已正确配置火山方舟 API KEY
- 建议使用现代浏览器访问以获得最佳体验
- 留意请求超时限制（60秒）
